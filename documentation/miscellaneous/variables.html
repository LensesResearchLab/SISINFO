Application Routes

This constant defines all the routes used in the application, organized by user role. The routes are stored as key-value pairs where the key is a descriptive name and the value is the actual URL path.

Structure:

  • Home route
  • Student routes (thesis management, graduate assistance, support)
  • Professor routes (undergraduate/postgraduate thesis, assistance management)
  • Coordinator routes (academic administration)
